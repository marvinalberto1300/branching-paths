# The Crownless King

## What is this?

**The Crownless King** is an interactive narrative website—a choice-driven story game inspired by decision-based games like Telltale's *The Walking Dead*, *Until Dawn*, and *Life is Strange*. Players navigate through a branching story across multiple acts, making choices at key moments that lead to different outcomes and endings. The story follows a crownless king facing invasion, betrayal, and ruin, with multiple pathways and endings based on player decisions.

## Why does it exist?

This project serves as a prototype and proof-of-concept for building **accessible, replayable interactive storytelling**. It demonstrates how to structure branching narratives with multiple decision points and endings, making interactive fiction accessible through a simple web-based format that anyone can play in a browser without installing games or special software.

## What tools did I use?

- **HTML** – Page structure and navigation (one page per scene)
- **CSS** – Consistent visual styling across all scenes
- **JavaScript** – Theme switching functionality (dark/light/auto modes)
- **Static site structure** – Simple file-based architecture with no backend, making it easy to host and maintain

This tech stack keeps the project lightweight, portable, and maintainable while focusing entirely on storytelling. The multi-page HTML structure makes branching paths straightforward to implement and debug.
